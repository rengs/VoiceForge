## VoiceForge 0.9

VoiceForge 0.9 是首个公开预览版本，提供面向 Apple Silicon macOS 的本地优先
中文语音输入闭环。

### 核心能力

- 按住 `Command + Shift + Space` 录音，松开后识别并输入当前光标位置。
- 使用 SenseVoiceSmall 在本机完成中文语音识别，可切换 Paraformer。
- 支持长语音连续录制，松开后按完整语句处理。
- 支持输入、改写、总结、翻译、生成和代码等意图路由。
- 普通听写不调用 LLM；Agent 可使用本地 Ollama 或 OpenAI-compatible 服务。
- 支持读取选中文字，并通过 macOS Accessibility API 回填或替换文本。
- 快捷键可在设置文件中修改并动态重新加载。
- 使用 SQLite 保存最近输入、用户偏好、专业词库和本地事件记录。
- 后端仅监听本机回环地址，使用本地 Ollama 时音频和 Agent 文本均无需上传。

### 安装

```bash
git clone --branch v0.9.0 https://github.com/rengs/VoiceForge.git "$HOME/VoiceForge"
cd "$HOME/VoiceForge"
./install.sh
```

安装脚本会创建独立 Python 环境、下载 ASR 模型、按需安装本地 Ollama、
构建 VoiceForge.app、安装到 `~/Applications` 并运行测试。

本版本发布源码安装包。VoiceForge.app 当前依赖安装脚本创建的项目环境，
因此未提供脱离项目目录运行的独立 DMG。

### 安全、隐私与许可

- VoiceForge 无厂商账号、订阅费或内置字数配额。
- 普通听写和默认本地模型处理均在用户设备上完成。
- 录音及 SQLite 数据保存在项目目录，当前未做应用层加密。
- 配置外部 OpenAI-compatible 服务后，Agent 文本会发送至该服务。
- VoiceForge 自有源代码采用 Apache License 2.0；第三方依赖及模型遵循
  各自许可证和使用条款。

### 已知限制

- 当前仅支持 Apple Silicon Mac 和 macOS 13 或更高版本。
- 首次安装需要联网下载依赖和模型，并需要约 3–6 GB 可用磁盘空间。
- App 当前使用本机临时签名，尚未提供 Developer ID 公证和自动更新。
- 识别结果在松开快捷键后生成，暂不提供边说边显示的增量字幕。
- Windows 11 迁移版不包含在本次发布中。
